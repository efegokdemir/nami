# Changelog

## [0.3.0] - 2026-10-04

- Expanded the theme to 45 merchant-facing sections and 11 reusable theme blocks, with more flexible Hero, Bento, merchandising and editorial composition.
- Improved product cards, product information blocks, galleries and recommendations, alongside the cart drawer/page, predictive search, and Shopify-native collection filtering and sorting.
- Added responsive and accessibility hardening, clearer empty states, and more flexible Theme Editor composition controls.
- Added an offline migration process and compatibility handling for saved v0.2.0 configurations. Review the [v0.2 upgrade guide](docs/upgrade-v02.md) before upgrading.

## [0.2.0] - 2026-10-02

- Refined the storefront visual system, typography, theme settings, image handling and responsive components.
- Updated homepage defaults and collection/product presentation.

## [0.1.0] - 2026-10-01

- Initial public beta theme architecture and commerce experience.
