# Contributing to Nami

Use a focused branch and keep one change per pull request. Do not add trackers, remote runtime services, fake commerce claims, credentials, or dependencies that are not required by Shopify's theme platform.

Run `shopify theme check --path nami` before opening a pull request. For local storefront work use `shopify theme dev --path nami` against a development store. Check keyboard navigation, reduced motion, mobile layout, empty states and Theme Editor behavior when changing sections.

Pull requests should explain the user-facing change, include exact validation commands, and avoid unrelated formatting or generated files.
