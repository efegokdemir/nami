# Nami v0.3.0 — public beta release notes (draft)

**Draft only. Not released.**

Nami v0.3.0 expands the free, open-source Shopify Online Store 2.0 theme into a broader merchant-configurable storefront while preserving Shopify's native templates, product forms, filtering, sorting, cart and Theme Editor architecture.

## What's included

- 45 merchant-facing sections and 11 reusable theme blocks, including Hero, Bento, editorial content, product and collection merchandising, FAQs, galleries, testimonials, comparisons and timelines.
- Reorderable product information blocks, three product gallery layouts, native product media handling, product recommendations, predictive search and cart drawer/page choices.
- Theme Editor controls for responsive layout, spacing, colour schemes, media and content composition, with nested Group blocks and app-block areas.
- Shared product cards, Shopify-native collection filtering and sorting, cart notes, localisation and responsive navigation.
- Accessibility and responsive improvements across keyboard interaction, focus, reduced motion, empty states and narrow viewports.
- P0/P1/P2 hardening and core-surface composition refinements, backed by migration tests, regression suites and Theme Check.

## Upgrade notes

Existing v0.2.0 stores must migrate saved JSON configuration before uploading v0.3.0. Use the offline `scripts/migrate-v02.cjs` procedure in [the upgrade guide](upgrade-v02.md), review every migration report, preserve the original v0.2 theme, and validate the staged v0.3 copy before upload. Unknown customizations stop migration for manual review.

## Known limitations

- The native product form does not select or submit selling plans; subscription-only products need an app integration that provides that flow.
- Native swatch metadata, Shopify-hosted product video and 3D model behavior were not verified in the QA catalog because no matching fixtures were available. The available video fixture was external media.
- One existing Sign in with Shop app block was verified in Theme Editor; this does not establish compatibility with every third-party app block.
- Physical-device testing remains outstanding. WebKit emitted Shopify `origin_trials` cross-origin script errors in the preview; no Nami asset failures were observed. Firefox smoke completed without page errors.
- The storefront theme is not an app and does not provide checkout customizations or payment processing beyond Shopify's native checkout.

This draft makes no performance benchmark or Lighthouse score claim. Release status and final artifact details will be added only after owner approval and the release process.
