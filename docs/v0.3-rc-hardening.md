# v0.3.0 release-candidate hardening — 2026-10-02

Scope: audit `41c301c` (v0.2.0) through `2025164` and harden existing capabilities. No merchant sections, blocks, layouts, controls, demo content or release were added. Work remains on `main`; previous releases are unchanged.

## Fixes and simplification

- Shared image arguments now preserve classes, loading, priority and alt text.
- Legacy product sections containing only information/app blocks retain core purchase controls; composed blocks retain their intentional order and omissions.
- Desktop promotional navigation preserves the parent destination. Collection app output is not gated by product availability. Native cart vendor/property preferences work; missing item images do not invoke image filters or emit empty image URLs.
- Blank FAQ, press, column, feature, timeline and comparison children hide live; editor logo placeholders remain selectable. Shared heading sizing targets legacy Split hero and Slideshow markup.
- One money formatter serves product, cart and search output. Carousel observers disconnect on section unload; resource requests abort and cannot update detached sections. Recently viewed inserts cards rather than section wrappers. Search/header references refresh after editor replacement.
- Cart changes serialize against current quantities and safely resolve replaced discount keys only when a unique corresponding allocation exists. Ambiguous replacements fail with a retry message instead of mutating a sibling. Pending additions cannot double-submit or re-enable a newly selected sold-out variant; complementary Quick Add does not inherit parent availability.
- Both accordion markup patterns retain their open indicator. Long-content wrapping and cart grid minimum sizing avoid narrow-width overflow; product images remain contained within merchant-selected ratios.
- Unset price bounds stay empty instead of filtering sorting results to zero-price products. Decimal price filters work, selected default sorting is accurate, duplicate Featured is removed, and active price filters can be cleared.
- Removed obsolete hero/Bento/collection-card/editorial/spotlight/placeholder and other replaced component selectors, duplicate quantity/reduced-motion rules, the invalid self-referencing spacing token, unnecessary component `!important` overrides, seven unused locale entries and an undeclared Featured collection product-source branch. Retained active Split hero, Slideshow and Recently viewed styles.
- Documentation now states the actual 45-section inventory and precise preset/motion, subscription and migration limits. Validator checks defaults, preset settings/types, template settings/types and duplicate block ordering.

## Remaining release risks

- Saved v0.2 comparison-column content requires manual migration to rows; legacy image `reverse`, carousel `limit`, removed eyebrow fields and Featured Product button copy are not automatically migrated. See [upgrade details](section-capabilities.md#upgrade-risks-from-v020).
- Subscription-only products require an app-provided selling-plan purchase integration; the native form does not supply one.
- Actual Shopify swatch metadata, Shopify-hosted product-video playback, 3D interaction and installed app output lack fixtures/coverage. The available Videographer product contains external YouTube media only; embed rendering is not playback certification.
- Presets/motion retain their documented limited effects; this pass does not redesign them. Safari, Firefox, physical devices, checkout/payment transactions and email delivery are not certified.

No v0.3.0 tag or release is created by this pass. A passing CI run is necessary but does not remove the migration and fixture-dependent risks above.
